🤖 Welcome to AI Class

New Here? Learn How to Use This Site

Welcome to AI Class! This website is designed to teach Artificial Intelligence step by step through 20 different classes.

📚 Step 1 — Choose a Class

Your learning journey starts with Class 1. The classes are arranged in order because each lesson helps you understand the lessons that follow.

📖 Step 2 — Study the Lesson

Every class contains a detailed explanation of its topic.

  • 📖 Detailed lesson
  • 🧠 Important things to understand
  • 💡 Real-life example
  • 📌 Lesson summary
  • 🧪 Interactive activity

🧪 Step 3 — Try the Activity

Some lessons contain an interactive Hide, Show and Toggle activity.

🎥 Step 4 — Watch the Video

When a video is available, click the Video button to watch the lesson video.

📝 Step 5 — Complete the Exercise

At the end of each lesson there is an exercise. The questions are based on what you have learned. You must answer correctly before moving to the next class.

🔓 Step 6 — Unlock the Next Class

Class 1 ➡️ Exercise ➡️ Class 2 ➡️ Exercise ➡️ Class 3

When you pass an exercise, the next class becomes unlocked.

⬅️ Step 7 — Back to Lobby

Use the Back to Lobby button to return to the main class selection page.

➡️ Step 8 — Next Class

After passing your exercise, click Next Class to continue.

⭐ Important Tips

  • Read every lesson carefully.
  • Watch the video when available.
  • Complete every exercise.
  • Review the lesson if you get an answer wrong.
  • Take notes when necessary.
  • Complete the classes in order.

🚀 You Are Ready!

You now know how to use the AI Class website.
